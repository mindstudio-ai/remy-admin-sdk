# @madewithremy/admin

**This repository is archived and no longer updated.**

The admin SDK and the `remy-admin` CLI, for managing production [Remy](https://goremy.ai) apps from a terminal or from code, are now developed in the Remy platform's own repository, alongside the management API they wrap, and released with it. The package is still published to npm under the same name, and its full documentation is on its npm page: [`@madewithremy/admin`](https://www.npmjs.com/package/@madewithremy/admin).

Nothing changes for anyone using it:

```bash
npm install -g @madewithremy/admin    # CLI on PATH
npm install @madewithremy/admin      # import layer in a project
```

The history here is kept as a record of how the SDK got to where it is.
